# 정책 데이터 작성 안내

정책을 수집한 기준과 필드별 작성 이유를 기록합니다. 기본 형식은 `docs/db-schema.md`를 따르며, 이번 서류 형식 변경은 팀에서 전달받은 합의 내용을 반영했습니다.

## 1. 파일별 역할

- `policies.json`: DB에 넣을 정책 데이터입니다.
- `P001_source.txt`: 공식 안내 원문과 출처를 보관합니다. 파일 자체가 앱에 자동으로 연결되지는 않습니다.
- `README.md`: 작성 기준, 팀에서 확인한 내용, 아직 확인이 필요한 내용을 남깁니다.

원문 파일명은 `{policy_key}_source.txt`로 정했습니다. `P001`은 정책 고유 번호, `source`는 원문 파일이라는 뜻입니다. 데이터와 원문을 쉽게 대조하기 위한 규칙이며, 프로그램에서 요구하는 이름은 아닙니다. 등록한 키는 정책명이나 목록 순서가 바뀌어도 유지합니다. 새 정책을 추가할 때는 팀 데이터와 키가 겹치지 않는지 확인합니다.

## 2. 공통 작성 기준

- 공식 자료를 기준으로 작성하고 출처와 실제 확인일을 기록합니다. 형식만 수정한 날에는 `checked_at`을 바꾸지 않습니다.
- `original_text`에는 출처별 원문과 구분용 머리말을 넣습니다. 작성자의 판단과 메모는 이 문서에 따로 남깁니다.
- `category`, `region` 등은 팀 명세의 코드값을 사용합니다.
- 확인하지 못한 내용은 추측해서 채우지 않습니다. `null`이나 빈 배열을 사용할 때도 필드의 의미를 먼저 확인합니다.
- `age_min`, `age_max`에는 현재 만 나이로 확실한 하한·상한만 넣습니다. 보호종료 당시 나이와 종료 후 경과기간처럼 현재 나이로 표현할 수 없는 조건은 `target_description`에 적습니다.
- `required_docs`는 `name`과 필요한 경우 `condition`을 가진 객체 배열로 작성합니다. 사용자별 완료·해당 없음 상태는 이 데이터에 넣지 않습니다.
- 쉬운 말 변환 전에는 `easy_text: null`, 검증 전에는 `easy_text_verified: false`로 둡니다.
- JSON에는 주석을 넣을 수 없어 작성 이유는 이 문서에 기록합니다.

## 3. P001 — 자립준비청년 자립수당 지급

자료 확인일은 2026-10-12이며, 2026-10-13에 팀 피드백을 반영해 형식을 수정했습니다. 현재는 쉬운 말 변환·검증과 DB 시드 확인이 남은 초안입니다.

### 출처

- 대표: [2026년 자립정보북](https://www.ncrc.or.kr/ncrc/na/ntt/selectNttInfo.do?mi=1177&nttSn=10594), 책자 28~29쪽(PDF 28~29페이지). 대상·지원 내용·서류 목록을 확인했습니다.
- 보완: [2026년 자립지원 업무매뉴얼 1권](https://www.ncrc.or.kr/ncrc/na/ntt/selectNttInfo.do?mi=1177&nttSn=10577), 책자 49쪽(PDF 29페이지 왼쪽). 신청 방식과 온라인 첨부 예외를 확인했습니다.
- 보완: [복지로](https://www.bokjiro.go.kr/ssis-tbu/twataa/wlfareInfo/moveTWAT52011M.do?wlfareInfoId=WLF00001175). 담당부처, 심의 예외, 신청 경로를 확인했습니다.

`source_url`은 자립정보북 게시물 주소입니다. 이에 맞춰 원문에 `[출처 B: 2026년 자립정보북 | 대표]`를 표시했습니다. 서울시·구미시 안내는 이번 서류 목록의 확정 근거로 사용하지 않았습니다.

### 필드별 작성 이유

**나이 조건**

백엔드 담당자 확인에 따라 `age_min`, `age_max`는 `null`로 유지했습니다. 보호종료 당시 나이와 종료 후 경과기간 등은 `target_description`에 적었습니다.

서버는 `null`이면 나이 필터를 통과시키므로, 나중에 노출되면 지역 조건이 맞는 아동·청소년 검색에도 나올 수 있습니다. 나이 필터 통과는 신청 자격이 있다는 뜻이 아니며, 세부 조건은 공식 원문을 확인하도록 안내합니다.

**여러 출처의 원문**

AI 담당자가 여러 출처를 한 필드에 넣는 방식을 확인했습니다. 중복되거나 표현이 다른 부분은 유지했고, 자립정보북과 업무매뉴얼에는 `[지원대상]`, `[신청방법]`, `[신청서류]` 등 머리말을 추가했습니다. 2026-10-13 재점검에서 정보북의 추출 문단 순서와 각주 기호를 지면에 맞게 바로잡았습니다. 정책 내용은 임의로 바꾸지 않았습니다. 머리말은 검색과 구분을 위해 붙인 것으로 공식 자료의 제목과 다를 수 있습니다.

**조건부 서류**

팀 합의에 따라 서류명은 `name`, 필요한 상황은 `condition`으로 나눴습니다. 예를 들어 위임장은 `name: "위임장"`, `condition: "대리 신청 시 (온라인 대리 신청 불가)"`로 작성했습니다.

앱에서는 조건을 표시하고 서류별로 '해당 없음'을 선택할 수 있도록 하기로 했습니다. 해당 없음인 서류는 서류 준비율 계산에서 제외하며, 단계 진행률에는 영향을 주지 않습니다. 실제 앱·서버 반영 여부는 아직 확인하지 않았습니다.

위임장·대리인 신분증·관계 증빙은 각각 준비해야 하므로 세 항목으로 나눴습니다.

### 택1 서류 — 임시 작성 방식

여러 서류 중 하나만 준비하면 되는 경우에는 대안을 한 항목의 `name`에 묶었습니다. 재무상담 확인서 또는 인정 교육 이수증 항목이 해당하며, 신분증도 인정되는 종류 중 1종을 선택하는 한 항목으로 유지했습니다.

데이터는 '여러 대안 중 하나 준비'를 뜻하도록 작성했습니다. 택1 자체를 '해당 없음' 조건으로 넣지는 않았습니다. 앱에서의 표시와 완료 처리 방식은 아직 합의 전입니다.

### 그 밖의 작성 이유

- `category=living_cost`: 매월 현금 지원으로 생활비 부담을 줄이는 정책이라 이 분류를 사용했습니다.
- `region=전국`: 중앙정부 정책입니다. 보완 자료를 제공한 기관의 소재지로 지역을 제한하지 않았습니다.
- `apply_url=null`: 로그인 이후 안정적으로 사용할 직접 신청 URL을 확인하지 못했습니다. 확인한 메뉴 경로는 `apply_method`에 적었습니다.
- `support_period`: 누구나 신청일부터 5년을 받는 것으로 오해하지 않도록 보호종료 유형별 기준을 남겼습니다.
- `is_active=false`: 아직 게시하지 않는 초안이라는 뜻입니다. 정책이 종료됐다는 뜻이 아닙니다.
- `easy_text=null`, `easy_text_verified=false`: 쉬운 말 변환과 원문 대조 검증이 아직 끝나지 않았습니다.

### 아직 확인할 내용

- 정보북에 금융감독원 교육과정은 '26년 6월 중 도입'으로 적혀 있습니다. 실제 시행·인정 여부를 다시 확인하기 전에는 확정된 대안으로 안내하지 않습니다.
- 온라인 사전신청 대상은 복지로와 업무매뉴얼의 표현이 다릅니다. 가정위탁 포함 여부는 담당기관 확인이 필요합니다.
- 원가정 복귀·재보호·심의 예외는 출처별 표현을 남겼으며, 사용자 개별 자격을 자동 확정하지 않습니다.

### 이번 수정의 확인 범위

JSON 문법, 서류 객체 형식, 대표 출처와 `source_url` 일치, 원문 문구 보존, 원문 파일과 `original_text` 일치를 확인했습니다. 팀에서 전달받은 새 서류 형식을 기준으로 수정했으며, 최신 저장소 명세 전체 대조·실제 DB 시드 실행·앱 연동·쉬운 말 검증은 아직 하지 않았습니다.

현재 비노출 초안이며, 앱 노출에는 `is_active`, `easy_text_verified`가 모두 `true`여야 합니다.


## 4. 2026-10-13 자료 재점검

국가아동권리보장원 게시물의 제목과 게시일을 다시 확인하고, 기존에 내려받은 정보북 28~29쪽과 업무매뉴얼 49쪽을 화면으로 대조했습니다. 월 50만 원, 지급일, 보호기간과 종료 유형별 대상 조건, 서류 목록은 보관 PDF에서 확인했습니다.

원가정 복귀 제외 조건은 정보북과 업무매뉴얼의 표현을 구분해 적었습니다. 신청서·신분증의 우편·팩스 제출 형태는 접수기관 확인 사항으로 남겼고, 위임장 등은 '대리 신청 시'로 표시했습니다. 정보북의 두 번째 '지원근거' 제목은 실제 PDF에도 그렇게 적혀 있어 유지했습니다.

복지로 본문은 이번 재접속에서 열리지 않았고 PDF 재다운로드도 실패했습니다. 따라서 보관 원문과의 대조 결과이며, 모든 출처의 최신 내용까지 재확인한 것은 아닙니다. `checked_at`은 기존 2026-10-12를 유지합니다. 복지로에만 근거가 있는 담당부서·심의 예외·상세 메뉴 경로는 이번에 새로 확인했다고 표시하지 않습니다.
